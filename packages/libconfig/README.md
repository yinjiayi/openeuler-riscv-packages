# libconfig

This directory packages upstream libconfig `1.8.2` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. Fedora 44 and Arch stable carry `1.8.2`; Debian stable, openSUSE Tumbleweed, and Ubuntu GA provide older lineage for the same independently verified upstream component. The official upstream distribution archive is pinned by SHA-256.

The frozen AUR metadata contained no exact-name `libconfig` entry. No AUR recipe or external distribution build script was read or executed. The build is network-free after source verification, runs upstream's C/C++ test suite, and compiles and executes installed C and C++ API smoke programs.

External source licenses remain those of the upstream project. The repository license covers only original packaging metadata, scripts, and documentation.
