# perl-test-cpan-meta

This directory packages upstream `https://metacpan.org/dist/Test-CPAN-Meta` version `0.25` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The archive SHA-256 matches MetaCPAN and the publisher's CHECKSUMS. The original
Artistic-2.0 copyright and grant notice (`LICENSE`) is shipped unchanged beside
the complete SPDX-pinned Artistic License 2.0 text. The stock MakeMaker test
harness is unmodified, including its upstream default author-only skips. The installed
smoke runs the YAML metadata validator against a synthetic local fixture.
