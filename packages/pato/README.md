# pato

This directory packages upstream `https://github.com/UDC-GAC/PATO` version `1.0.1` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

Downstream release `3` matches the SPEC source root to the pinned archive's exact `PATO-1.0.1` top-level directory and configures explicit CMake source and out-of-source build directories while preserving the existing OpenMP and test behavior. The RISC-V build status remains `unknown` pending fresh CI evidence.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
