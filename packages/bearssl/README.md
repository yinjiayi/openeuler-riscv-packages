# BearSSL

This directory packages upstream BearSSL 0.6 for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. It builds the `brssl` tool plus a `bearssl-devel` static-library package from the official pinned archive.

The upstream MIT license governs the fetched source. Apache-2.0 covers only this repository's original packaging material.
