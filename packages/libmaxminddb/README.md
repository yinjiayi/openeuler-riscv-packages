# libmaxminddb

This directory packages libmaxminddb `1.13.3` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. Fedora 44 was the priority discovery source; Arch stable, Debian stable, openSUSE Tumbleweed, and Ubuntu GA corroborated the same official stable component. The upstream release asset is pinned by SHA-256.

No external distribution recipe or AUR content was executed. Upstream C, C++, command-line, and symbol tests remain mandatory, followed by an installed API smoke test, with no network allowed during the build.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
