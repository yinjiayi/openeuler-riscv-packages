# Class::Std::Utils

This directory packages upstream `https://metacpan.org/dist/Class-Std-Utils` version `0.0.3` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The fixed CPAN archive uses the upstream version spelling `v0.0.3`.
It is pinned by SHA-256 and corroborated by signed PAUSE CHECKSUMS and
the byte-identical Debian orig archive. The original Perl dual-license
grant in the README and module is preserved with both full license texts.

The default MakeMaker tests run unchanged, including the POD and
POD-coverage files. The installed smoke checks anonymous scalar handling
and stable identity. No source patch is required.
