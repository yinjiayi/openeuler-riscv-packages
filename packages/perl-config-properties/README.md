# perl-config-properties

This directory packages upstream `https://metacpan.org/release/Config-Properties` version `1.80` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The fixed archive checksum is required. The PAUSE signature covers the
author's checksum index, not the archive itself. The original README is
included for its license and author notices. All upstream default tests,
including UTF-8 parsing, run unchanged.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
