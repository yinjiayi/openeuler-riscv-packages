# libsigsegv

GNU libsigsegv 2.15 for openEuler 24.03 LTS SP3 `riscv64`/RVA23. Official
GNU bytes are SHA-256 pinned and archive/license inspected. Frozen stable
lineage spans Arch, Debian, Fedora 44, openSUSE Tumbleweed, and Ubuntu; no AUR
recipe or distribution packaging script was read or executed.
