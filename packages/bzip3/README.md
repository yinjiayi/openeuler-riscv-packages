# bzip3

This directory packages upstream `bzip3` 1.5.3 for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. The official GitHub tag archive is pinned by SHA-256 in `sources.yaml`; distribution records are discovery lineage only.

The compiled library and command are LGPL-3.0-or-later with bundled Apache-2.0 libsais code; the installed `bz3grep` helper is BSD-2-Clause. Apache-2.0 covers only this repository's original packaging material. Reviewed-registry enrichment is a separate infrastructure change.
