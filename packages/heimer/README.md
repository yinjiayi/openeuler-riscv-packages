# heimer

This directory packages upstream `https://github.com/juzzlin/heimer` version `4.5.0` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

Release 2 matches GitHub's case-preserving `Heimer-4.5.0` archive root, declares the complete official Qt5 build dependency closure, and explicitly enables Heimer's `BUILD_TESTS` option. The full upstream CTest suite remains the `%check` gate.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
