# time

This directory packages GNU time `1.10` for openEuler 24.03 LTS SP3 on
`riscv64`/RVA23. The official GNU release archive is independently SHA-256
pinned and passed single-root, path, link, and special-entry safety inspection.

The immutable `discovery-20260808T165000Z-9a89920c269462cd` snapshot records
Arch `1.10-1`, Debian `1.9-0.2`, Fedora 44 GA `1.9-28.fc44`, openSUSE
Tumbleweed `1.10-1.4`, and Ubuntu GA `1.9-0.4`. It has no canonical stable AUR
row for this component. No AUR recipe or distribution spec was read or
executed. The full upstream `make check` suite remains enabled, and installed
smoke checks both the reported version and a real child-process exit status.

External source licenses remain upstream's. Apache-2.0 covers only this
repository's original packaging metadata, scripts, tests, and documentation.
