# libtie-cycle-sinewave-perl

This directory packages upstream `https://metacpan.org/dist/Tie-Cycle-Sinewave` version `0.05` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The fixed CPAN archive matches the historical PAUSE signed checksum and Debian
stable original. Install the original README with its copyright grant and the
two complete Perl license texts. The unmodified default MakeMaker suite
includes an author-only file that self-skips without its upstream opt-in.
The installed smoke verifies quarter-cycle samples and both extrema callbacks.
