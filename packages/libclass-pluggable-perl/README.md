# libclass-pluggable-perl

This directory packages upstream `https://metacpan.org/dist/Class-Pluggable` version `0.022` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The original README and module retain Ken Takeshige's Perl dual-license
grant; both official full texts are shipped. The exact release matches the
signed PAUSE checksum and Debian stable original archive.

The original thirteen default assertions remain unchanged. The installed
smoke registers one explicit preloaded plugin and verifies method and hook
dispatch. The plugin interface is for trusted application-selected code.
