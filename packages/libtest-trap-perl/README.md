# Test::Trap

The recipe runs the original Module::Build default test suite, including its
generated fork and SystemSafe test scripts. It retains the suite's upstream TODO
and the optional Test::Refcount check, which self-skips when that module is
unavailable. The original README carries the upstream Perl license grant.

This directory packages upstream `https://metacpan.org/dist/Test-Trap` version `0.3.5` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
