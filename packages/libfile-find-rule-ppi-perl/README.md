# perl-file-find-rule-ppi

This directory packages upstream `https://metacpan.org/dist/File-Find-Rule-PPI` version `1.07` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The fixed CPAN release is verified against MetaCPAN, signed PAUSE checksums, and Fedora 44 GA lineage. The original same-Perl license and the generated MakeMaker, Test::ReportPrereqs and embedded version::LAX notices are retained from pinned donor archives. No donor code is executed or installed.

The recipe preserves all three upstream default tests and their parser fixtures. The installed smoke parses two controlled Perl source fixtures and checks that the comment rule selects only the commented file.
