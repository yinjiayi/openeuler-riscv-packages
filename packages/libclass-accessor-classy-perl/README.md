# perl-class-accessor-classy

This directory packages upstream `https://metacpan.org/dist/Class-Accessor-Classy` version `0.9.1` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The original upstream archive name and root retain their `v` prefix. The original Build.PL runs the unfiltered default suite. Installation suppresses only the generated `.packlist`; the module and its manual are kept. The original module POD contains the author's license grant, and the installed smoke exercises both read-only and writable accessors.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
