# cabextract

This directory packages upstream `cabextract` 1.11 for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. It uses the bundled libmspack sources from the official pinned archive and runs the upstream test suite offline.

The executable combines GPL-2.0-or-later cabextract code with bundled
LGPL-2.1-only libmspack code. The source archive also contains
LGPL-2.0-or-later GNU portability code. Apache-2.0 covers only this
repository's original packaging material.
