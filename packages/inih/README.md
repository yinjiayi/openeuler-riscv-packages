# inih

This directory packages inih release r62 for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. It builds both the C library and C++ INIReader wrapper and runs the bundled baseline-comparison suite with Meson.

The immutable discovery record corroborates the component across Arch stable, AUR metadata, Debian stable, Fedora GA, openSUSE Tumbleweed, and Ubuntu GA. The `r62` tag prefix is normalized only by the reviewed official-release resolver. AUR remains metadata lineage and is never executed.

The upstream BSD-3-Clause license governs fetched source. Apache-2.0 covers only this repository's original packaging material.
