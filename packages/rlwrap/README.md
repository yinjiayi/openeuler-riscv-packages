# rlwrap

This directory packages upstream rlwrap 0.48 for openEuler 24.03 LTS SP3 on
riscv64/RVA23. The official GitHub release archive is pinned by SHA-256 in
sources.yaml; the frozen distribution records are discovery lineage only.

The source is GPL-2.0-or-later. The package keeps the upstream make check
entry point enabled. Target Package CI may fetch the verified source and build
dependencies online; no target build was performed in the local preparation.
