# python-pyuca

Official stable Pyuca 1.2 is pinned to Git commit
`d751d694a90ab9d8789263822e02ae822d251e2c`; the full archive SHA-256 is
`e1e0880ffa05260a111e9d0652443f728896eee4a48448c1dff2cab276cf9435`.
Released runtime/data bytes match the fixed official PyPI 1.2 source. All 40
original Git files (181,425,190 unpacked bytes) remain unchanged, including full,
not shortened, Unicode conformance fixtures. MIT and Unicode-DFS-2015 grants and
all original notices are retained; no data has been regenerated or modified.

The selected original Travis default is `flake8 .`, followed by the original
coverage unit, doctest and full-conformance commands, with unchanged source-check arguments.
The installed check runs full original lint, then the same runtime checks using
RPM-owned code and all five original installed collation tables. Original Python
version-dependent skips remain. CONTRIBUTING's 100% coverage expectation is
recorded, and the actual report is printed; no new fail-under flag is invented.
Coveralls external reporting is not performed. Historical Python 2.7–3.7-dev
matrices are not claimed: target Python 3.11 compatibility must be proved by CI.
Full conformance is a correctness check, not a timing or performance claim.

The original alternate tox `[]` is its empty-posargs shorthand, verified by
inert inspection of the supplied official tox parser; it is not a literal
directory or a new test filter. This recipe selects the complete Travis route,
not a shortened tox/unit-only substitute. No original tests, lint, assertions,
fixtures or skip conditions are removed. Build-time defaults use a pristine
archive so generated build/lib copies cannot enter collection. Installed checks
exclude the source runtime from the execution scratch tree and bind imports,
doctest's installed-file symlink, data, fixtures and retained originals to their
SHA-256 values and RPM ownership.

Frozen distribution discovery rows are provenance, not current target supply or
upstream version claims. Full current canonical/provider namespace and dependency
closure are reviewed separately. Metadata feasibility is not a DNF transaction,
ABI proof or successful target execution. Local checks are repository/static and
offline source-only; package build, installation and full defaults run in CI.
No RPM/SRPM URL or publication status is asserted before physical verification.

Target command mapping: official openEuler python3-coverage 7.3.2 installs
versioned console scripts, not an unversioned `coverage` executable. Both
source and installed checks invoke the same `coverage.cmdline.main` through
`python3 -m coverage`, preserving every original subcommand and argument.
The first CI failed before unit/doctest/conformance execution; this corrects
only the target CLI entrypoint, not upstream code or default checks. All 40
original files, five full Unicode fixtures, skips and license notices remain.

Installed measurement compatibility: coverage 7.3.2 treats an existing
`--source pyuca` directory as a path. The fresh execution scratch contains that
directory only for the original doctest argument's installed-file symlink, so
the old selector excluded the real installed runtime and printed 0% despite
functional checks passing. Only the three installed `--source` values now use
the already verified absolute RPM-owned package directory. Branch/append flags,
unit/doctest/full-fixture commands, all 24 units and nine original version skips,
source SPEC and upstream files are unchanged. The original report remains; an
additional fresh JSON report must contain exactly all four SHA-matching,
RPM-owned modules, real executed lines and branch data across the original 188
statements. No new percentage fail-under threshold is imposed. Source 97% does
not satisfy CONTRIBUTING's aspirational 100%, and replacement CI must separately
prove installed measurement; the prior installed 0% is not accepted as coverage.
