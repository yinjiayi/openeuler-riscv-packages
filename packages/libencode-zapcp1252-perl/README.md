# libencode-zapcp1252-perl

This directory packages upstream `https://metacpan.org/dist/Encode-ZapCP1252` version `0.40` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The signed CPAN archive and Debian stable original have different gzip
wrappers but identical decompressed tar bytes. The recipe uses the original
`Build.PL` and all default tests without changes. Installed smoke checks
both UTF-8 and ASCII conversion.

The source contains a fallback `Makefile.PL` generated by
`Module::Build::Compat` 0.4229. Its pinned donor is used only to extract
Ken Williams's original notice into plain text; no donor Perl code is installed
or run. Both full Perl license texts and the upstream notice are included.
