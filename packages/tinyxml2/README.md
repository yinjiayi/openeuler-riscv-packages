# tinyxml2

This directory packages TinyXML-2 11.0.0 for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. It builds the shared library, installs CMake and pkg-config metadata, and runs the upstream XML regression executable under CTest.

The immutable discovery record corroborates the component across Arch stable, AUR metadata, Debian stable, Fedora GA, openSUSE Tumbleweed, and Ubuntu GA. Only the inspected official stable archive and pinned SHA-256 are trusted; AUR packaging is not executed.

The upstream Zlib license governs fetched source. Apache-2.0 covers only this repository's original packaging material.
