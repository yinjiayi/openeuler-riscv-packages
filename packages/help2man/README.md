# help2man

GNU help2man 1.49.3 for openEuler 24.03 LTS SP3 `riscv64`/RVA23. The
official GNU archive is SHA-256 pinned and archive/license inspected. Frozen
lineage records Arch, Debian stable, Fedora 44 GA, openSUSE Tumbleweed, and
Ubuntu GA. No AUR recipe or distribution packaging script was read or run.

Upstream ships no standalone test suite; `%check` exercises the built program
against a deterministic local fixture, while installed smoke validates output.
Apache-2.0 covers this repository's packaging material, not upstream sources.
