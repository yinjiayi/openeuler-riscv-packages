# Log::Trace 1.070 — dependency-held draft

This package is a proposal, not a successful target build. The fixed official
SP3 RVA23 repository lacks `perl-Data-Serializer` and
`perl(Data::Serializer::Data::Dumper)`. Both are declared as ordinary build and
runtime requirements. The current proposal/PR must remain draft until a reviewed supplier
is available and exact-head hosted CI verifies dependencies, complete tests,
actual RPM/SRPM and installed smoke. No dependency filter, feature fallback,
test deletion or skipped-test acceptance is permitted.
Metadata is `update-disabled` with automatic updates disabled during this
dependency hold; activation needs separately accepted dependency/target gates.

## Target dependency and correctness gates

Official checksum-bound target metadata supplies Perl 5.38, Carp 1.50,
Fcntl, Time::HiRes 1.9775, Data::Dumper 2.183, Sys::Syslog 0.36,
PathTools, MakeMaker, Test::More, Harness, Test::Pod and Test::Pod::Coverage;
it does not supply Serializer or its Data::Dumper backend. This describes the
reviewed snapshot, not a future install transaction or all optional backends.

The unchanged module computes runtime VERSION `1.070` using sprintf on
Revision `1.70`. Only the exact autogenerated `perl(Log::Trace)` capability
is excluded and accurate `1.070` provided explicitly; all other generated
dependencies remain enabled. Static lexical ambiguity motivates this choice;
actual target generator and installed capability evidence still require CI.

`%check` first preloads every default-test helper, including Serializer and
its backend, then runs original `make test` and a strict Harness over all 13
files. Eleven trace files plan 80 assertions; the two POD files enumerate
their assertions dynamically, so no executed total is invented. Every
observed assertion must pass, with zero skipped files/assertions, TODO, bonus
or failures. A private owned 0700 TMPDIR isolates upstream's fixed basename
without editing tests. Installed smoke checks module/notice bytes, exact
VERSION/provider, buffer/callback/level semantics, Data::Dumper and Serializer
dump outputs. No upstream tests, compilation or RPM/QEMU run is performed
locally. Syslog daemon, threading, native file-lock/alarm/timing accuracy and
performance acceptance are not claimed by these functional checks.
