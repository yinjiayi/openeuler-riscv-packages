# libxml-namespacefactory-perl

This directory packages upstream `https://metacpan.org/dist/XML-NamespaceFactory` version `1.02` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The fixed CPAN archive matches Debian stable's original source for
`libxml-namespacefactory-perl` 1.02-3 byte for byte. Its checksum is present
in the signed PAUSE manifest. The upstream LICENSE contains both license
texts. The generated MakeMaker file matches the Dist::Zilla 5.019 template,
whose separate copyright notice is retained.

The original default tests are unchanged. The installed smoke checks
ordinary and punctuated local names in Clark notation, which puts the
namespace URI in braces before the local name.
