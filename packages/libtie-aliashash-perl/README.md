# Tie::AliasHash

This directory packages the official CPAN Tie-AliasHash 1.02 release for
openEuler 24.03 LTS SP3 on riscv64/RVA23. It is a noarch Perl module.

The fixed CPAN source digest agrees with authorized MetaCPAN and publisher
CHECKSUMS. The author's Build.PL declares the Perl license, corroborated by
the release metadata and Debian's upstream copyright record. Both complete
license texts from the Perl project are pinned alongside the upstream archive.
The recipe keeps the unmodified Module::Build default test action and adds no
RISC-V patches. Local host testing is not target build or install evidence.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
