# libarchive

This package tracks the official libarchive 3.8.9 stable release for
openEuler 24.03 LTS SP3 on RVA23 riscv64. The upstream release asset is
pinned by SHA-256, the existing `libarchive.so.13` ABI, command-package split,
and `libarchive-help` documentation split are preserved, and the complete
serial upstream check suite is enabled.
