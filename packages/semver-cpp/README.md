# semver-cpp

This directory packages upstream `https://github.com/Neargye/semver` version `1.0.0` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

Packaging release 2 selects the verified `semver-1.0.0` top-level directory, uses an explicit CMake build directory, and enables the bundled doctest suite for CTest.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
