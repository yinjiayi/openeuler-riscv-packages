# libunwind

This directory packages upstream libunwind 1.8.3 for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. CI builds shared libraries and development files with the pinned archive and runs the complete upstream test suite under QEMU user mode.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
