# catimg

This directory packages upstream `catimg` 2.8.0 for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. The official GitHub tag archive is pinned by SHA-256 in `sources.yaml`; distribution records are discovery lineage only.

The upstream MIT license governs the fetched source, including the installed zsh completion. Apache-2.0 covers only this repository's original packaging material. Reviewed-registry enrichment is a separate infrastructure change.
