# Test::Env

This directory packages upstream `https://metacpan.org/dist/Test-Env` version `1.088` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The CPAN release archive is pinned to its publisher-verified SHA-256. The archive's original Artistic License 2.0 text is installed unchanged. The original default MakeMaker test target runs environment-variable behavior tests and both POD checks. No patch or vendored dependency is used.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
