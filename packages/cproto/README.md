# cproto

This directory packages upstream cproto 4.8a for openEuler 24.03 LTS SP3 on
riscv64/RVA23. The official invisible-mirror archive is pinned by SHA-256 in
sources.yaml; the frozen distribution records are discovery lineage only.

Most cproto sources are public domain; the autoconf support is MIT-X11. The
upstream make check harness remains enabled. Target Package CI may fetch the
verified source and dependencies online; no target build was performed locally.
