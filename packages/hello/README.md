# hello

This directory packages upstream `https://www.gnu.org/software/hello/` version `2.12.3` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. The source archive is reviewed in `catalog/upstream-releases.yaml` and pinned by SHA-256 in `sources.yaml`.

The complete upstream `make check` suite remains enabled; the installed smoke test verifies the greeting, version, and target RPM architecture.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
