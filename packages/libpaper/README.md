# libpaper

This directory packages upstream `https://github.com/rrthomas/libpaper` version `2.3.0` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. Upstream 2.3 installs the `paper` command, which supersedes the older paper utilities; the SPEC follows the files present in the verified release archive and retains the complete upstream test suite.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
