## Build and tests

Build dependencies are `make`, `perl`, `perl-ExtUtils-MakeMaker`,
`perl-Test-Harness`, `perl-podlators` and `perl-generators`; runtime imports
are `AutoLoader`, `Exporter`, `strict` and `vars`.
CI must prepare those dependencies against the fixed official target repo
before the offline build; CPAN bootstrapping or network access by package
build logic is not required. Runtime dependencies and module capabilities
are retained explicitly and generated by the target Perl RPM generators.

`%prep` and `%check` enforce SHA-256 of every original source file.
`%check` runs the complete unfiltered MakeMaker default `test.pl`: one TAP
module-load assertion, followed by the original `x**y<<2+z` translation
example with a nonempty-result check. This is limited upstream coverage,
not a broad functional or performance test.
Installed smoke additionally asserts version, RPM/module capability,
arithmetic precedence, grouping, the original example, unary/function
translation and invalid-token diagnostics. It checks the installed module
and all three license files against their original digests, without a
source-tree library path. These smoke outcomes are requirements, not
locally observed passes.

The module and POD manual are owned by this RPM. MakeMaker's possible
AutoSplit output is included only under this package's exact
`auto/Affix/Infix2Postfix` tree; shared vendor and `auto` roots are not owned.
`.packlist` and `perllocal.pod` are excluded from the installed package.

The upstream README carries a historical token-prefix `BUGS` warning;
`Changes` also reports a token-generation fix in 0.02. Both are preserved
without claiming that either describes a freshly verified modern failure.
No default tests are removed, no RISC-V patch is invented, and target
RPM build/install/smoke remains pending exact hosted CI evidence.
