# perl-time-progress

This directory packages upstream `https://metacpan.org/release/Time-Progress` version `2.15` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The fixed CPAN archive checksum is required. The author index signature applies
to the checksum index, not to the archive itself. The upstream README is
included for its original license notice, and all default tests run unchanged.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
