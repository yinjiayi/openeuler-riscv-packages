# perl-sub-recursive

This directory packages upstream `https://metacpan.org/dist/Sub-Recursive` version `0.05` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The original Makefile.PL runs the full default suite. The package installs the original LICENSE, module, and manual, omitting only generated Perl installer metadata. The installed smoke checks both a directly recursive factorial and mutually recursive odd/even predicates.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
