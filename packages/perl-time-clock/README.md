# perl-time-clock

This directory packages upstream `https://metacpan.org/release/Time-Clock` version `1.03` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The fixed release comes from the CPAN author directory. The archive checksum is
required; the author index signature applies to the checksum index, not to the
archive itself. The module's original licensing POD is included as
`LICENSE-POD`. All default tests run unchanged, including the POD check.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
