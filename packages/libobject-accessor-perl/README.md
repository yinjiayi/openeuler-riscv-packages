# libobject-accessor-perl

This directory packages upstream `https://metacpan.org/dist/Object-Accessor` version `0.48` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The original module retains Jos Boumans's Perl dual grant. The source archive's Makefile.PL contains the exact `WriteMakefile1` helper from App-EUMM-Upgrade 0.21, copyright 2009 Alexandr Ciornii, GPL-3.0-only. It is used only during the build; both grants and the separate helper notice are retained.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
