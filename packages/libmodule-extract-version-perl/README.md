# Module::Extract::VERSION

This directory packages upstream `https://metacpan.org/dist/Module-Extract-VERSION` version `1.123` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The noarch RPM is named `perl-module-extract-version`. Its fixed official
CPAN archive SHA-256 matches MetaCPAN and the publisher CHECKSUMS. The bundled
Artistic-2.0 license is retained verbatim.

The original MakeMaker tests are not replaced, including both POD suites.
The smoke test uses the installed module to extract the version from a
minimal Perl source fixture. Actual RISC-V build, installation, tests and
RPM/SRPM evidence are to be established by exact hosted CI.
