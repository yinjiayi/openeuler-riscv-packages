# google-crc32c

Google CRC32C 1.1.2 for openEuler 24.03 LTS SP3 on riscv64/RVA23. The
official tag archive is pinned by SHA-256. Its release archive contains empty
third-party submodule directories, so optional benchmark, logging, and
upstream GoogleTest targets are disabled; the installed C API is checked with
the RFC 3720 CRC32C vector.
