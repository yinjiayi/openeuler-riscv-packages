# perl-test-directory

This directory packages upstream `https://metacpan.org/dist/Test-Directory` version `0.052` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The fixed CPAN archive SHA-256 matches MetaCPAN and signed PAUSE CHECKSUMS.
The original README and module POD retain Steve Sanbeg's same-Perl grant.
Fedora 44 GA is discovery lineage, not a substitute source.

All nine original default tests run without exclusions. Installed smoke
uses a private directory to check fixture creation, lookup, and cleanup.
