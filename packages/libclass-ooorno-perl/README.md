# perl-class-ooorno

This directory packages upstream `https://metacpan.org/dist/Class-OOorNO` version `0.011` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The official archive SHA-256 agrees with MetaCPAN and signed PAUSE CHECKSUMS.
The original COPYING and author README record the same-Perl license grant.
The recipe uses the unchanged Makefile.PL and all original tests. The
installed smoke verifies option and positional argument classification.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
