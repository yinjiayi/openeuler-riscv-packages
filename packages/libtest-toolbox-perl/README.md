# perl-test-toolbox

This directory packages upstream `https://metacpan.org/dist/Test-Toolbox` version `0.4` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The fixed CPAN archive SHA-256 matches MetaCPAN and signed PAUSE CHECKSUMS.
The complete original LICENSE retains Miko O'Sullivan and Christopher
J. Madsen's notices. Fedora 44 GA is discovery lineage.

All 23 unchanged default assertions run. The developer-only display and
global marker hooks are not enabled. Installed smoke checks unordered
comparisons and captured errors, and the separate upstream POD is retained.
