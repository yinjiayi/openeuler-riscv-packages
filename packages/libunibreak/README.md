# libunibreak

This directory packages libunibreak 7.0 for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. It uses the official release asset containing generated Unicode tables and runs the bundled line, word, and grapheme break conformance tests without regenerating data or accessing the network.

The immutable discovery record corroborates the component across Arch stable, AUR metadata, Debian stable, Fedora GA, openSUSE Tumbleweed, and Ubuntu GA. The release asset SHA-256 matched GitHub's publisher digest. AUR is retained only as untrusted metadata lineage.

The upstream Zlib license governs fetched source. Apache-2.0 covers only this repository's original packaging material.
