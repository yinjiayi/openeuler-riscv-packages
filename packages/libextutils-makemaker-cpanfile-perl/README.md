# perl-extutils-makemaker-cpanfile

This directory packages upstream `https://metacpan.org/dist/ExtUtils-MakeMaker-CPANfile` version `0.11` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The fixed official archive is pinned by SHA-256 and corroborated by signed PAUSE CHECKSUMS. The original LICENSE contains the Perl dual grant and both complete license texts. Debian and Fedora catalog entries establish lineage, and Fedora also carries 0.11. No source patch is needed.

The noarch recipe runs all original MakeMaker default tests. Installed smoke checks that a cpanfile's runtime and test requirements and the extension's own configure requirement reach MYMETA.json.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
