# libmodule

This directory packages upstream `https://github.com/FedeDP/libmodule` version `5.0.2` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

Release 2 uses the repository's separate CMake build directory, declares the
complete C/C++ and CMocka build requirements, and enables the upstream
`ModuleTest` suite.
