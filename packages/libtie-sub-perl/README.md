# tie-sub

This directory packages upstream `https://metacpan.org/dist/Tie-Sub` version `1.001` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The author's README grants redistribution on the same terms as Perl itself;
retain its notice alongside both full Perl license texts. The upstream
`Makefile.PL` was generated by `Module::Build::Compat` 0.3800, whose
original source grants the same terms. It invokes MakeMaker directly without
a bundled loader or network installation. Neither the original source nor
test files are modified.

`make test TEST_VERBOSE=1` executes the upstream default suite. Its
behavior and both POD checks are retained; author/release-only checks retain
their original conditions and are not enabled in normal packaging.
