# fping

fping 5.5 for openEuler 24.03 LTS SP3 riscv64/RVA23. Official release bytes
are SHA-256 pinned and archive/license inspected. Frozen Arch, Debian,
Fedora 44, openSUSE, and Ubuntu stable lineage was cross-checked without
executing recipes. Upstream ships no registered standalone test suite in the
release; the RPM check exercises deterministic version, help, and generation.
