# gmime3

This directory packages upstream `https://github.com/jstedfast/gmime` version `3.2.15` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The source is upstream's `gmime-3.2.15.tar.xz` release asset. Its committed SHA-256 matches the checksum published with that release, and the release archive contains the generated `configure` script used by the RPM build.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
