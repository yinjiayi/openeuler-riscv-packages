# indent

GNU indent 2.2.13 for openEuler 24.03 LTS SP3 `riscv64`/RVA23. The official
GNU release is SHA-256 pinned and archive/license inspected. Stable Arch,
Debian, Fedora 44, openSUSE Tumbleweed, and Ubuntu lineage is recorded without
reading or executing distribution recipes or AUR content.

Release 2 aligns the installed smoke assertion with GNU style, which places
the procedure name on the line after its return type. Release 3 verifies the
version output while accepting GNU Indent's intentional `EX_USAGE` status for
the informational option, then retains the compile-validating formatted-output
check.
