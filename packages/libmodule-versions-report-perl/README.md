# perl-module-versions-report

This directory packages upstream `https://metacpan.org/dist/Module-Versions-Report` version `1.06` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The fixed CPAN archive SHA-256 matches MetaCPAN and signed PAUSE CHECKSUMS.
The original README and module POD preserve Sean M. Burke's same-Perl
grant. Fedora 44 GA and Debian are discovery lineage, not source substitutes.

The unmodified Test.pm suite exercises 33 assertions in two files. The
installed smoke checks that the report names the installed module and the
version of a loaded core module.
