# libnet-cidr-perl

This directory packages upstream `https://metacpan.org/dist/Net-CIDR` version `0.27` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The MakeMaker adapter excludes only the archived upstream RPM-spec generator. The source remains unmodified, and the original test suite, including its leading-zero regression, runs unchanged.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
