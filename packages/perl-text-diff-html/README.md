# perl-text-diff-html

This directory packages upstream `https://metacpan.org/dist/Text-Diff-HTML` version `0.08` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The source digest is published by MetaCPAN and the PAUSE author checksum file. The original `Build.PL` runs the original behavior and POD tests; `Test::Pod` is a build dependency so its test does not skip. The installation check renders a local text change and verifies that HTML metacharacters are escaped.

The sole patch adds a notice and changes no upstream code or tests. The unmodified source archive includes an optional `Makefile.PL` generated by `Module::Build::Compat` 0.4224. The patch retains the copyright and license grant from the donor's `lib/Module/Build/Compat.pm` POD; the donor archive's root `LICENSE` is a placeholder. Both this notice and Text::Diff::HTML's original full `LICENSE` are installed. Reassess the patch when a release drops the generated wrapper or itself carries the required notice.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
