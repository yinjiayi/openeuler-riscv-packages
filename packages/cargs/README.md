# Cargs 1.2.0

Official stable tag v1.2.0 is fixed to commit
`0fbac1a0c6ebb7ecd72f0d7ae89c2b79eb3a12eb`, with all 49 Git files/modes
matched to the archive SHA-256 in sources.yaml. The original MIT terms are
included. Historical AUR data is discovery only and is never executed.

Upstream's tag contains `project(cargs VERSION 1.1.0)`. RPM version 1.2.0
identifies the released tag, while installed CMake and pkg-config metadata
truthfully retain 1.1.0. The one packaging patch makes pkg-config's library
directory agree with the configured GNUInstallDirs lib64 directory. It does
not alter implementation, tests, test registry or warning policy.

Keep the default static library and original installation layout, with
cargs-devel/cargs-static aliases for this development package. The demo is
built and exercised, as upstream CI requests; upstream does not install it.
No standalone ELF is installed, so no empty debug subpackage is requested.

The complete original 23-entry CTest registry and bare all-tests runner are
both executed in %check. Source-only QA retains the original main.c,
option_test.c and definitions.h, plus tests.h generated by the unchanged
upstream CMake registry. Staged and installed acceptance recompiles that
original runner against the actual installed header/static archive, runs all
23 cases without arguments, and separately replays every registry entry.
No filters, source interposition, feature disabling, assertions suppression
or ignored failures. Target build/install results are obtained only in CI.
