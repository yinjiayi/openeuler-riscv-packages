# media-downloader

This directory packages upstream `https://github.com/mhogomchungu/media-downloader` version `5.6.3` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

Upstream CMake requires the Qt Core, Widgets, and Network components. Release `2` declares the official `qt6-qtbase-devel` provider and selects Qt 6 explicitly; the existing CTest gate remains enabled.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
