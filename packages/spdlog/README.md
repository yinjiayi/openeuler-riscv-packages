# spdlog

This directory packages upstream `https://github.com/gabime/spdlog` version `1.17.0` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The immutable discovery snapshot cross-checks all six configured distribution sources. The official stable tag archive and upstream-pinned Catch2 3.5.0 test source are fetched and SHA-256 verified before the offline build; no AUR recipe or distribution build hook is read or executed.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
