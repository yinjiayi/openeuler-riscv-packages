# lmdb
LMDB 0.9.35 for openEuler 24.03 LTS SP3 riscv64/RVA23. Official OpenLDAP tag bytes are SHA-pinned and archive/OpenLDAP license inspected. Frozen Arch, Debian, Fedora 44, openSUSE and Ubuntu metadata was cross-checked; no recipe executed. All five original upstream mtest programs and the installed API smoke are required without reduced locking or mapping semantics. The full mtest sequence shares an explicitly initialized `testdb` environment, matching the prerequisite established by upstream's `test` target. Exact-head GitHub Actions run `33524119746` showed that even the default `mdb_env_open` call with flags `0` returns `EOPNOTSUPP` under riscv64 QEMU user mode after compilation and installation succeed, so native RISC-V is required to validate LMDB's shared-lock and memory-map behavior. The file manifest includes the four `man1` pages present in the archive; this release does not ship a `man3` page.
