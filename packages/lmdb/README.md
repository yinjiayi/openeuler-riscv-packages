# lmdb
LMDB 0.9.35 for openEuler 24.03 LTS SP3 riscv64/RVA23. Official OpenLDAP tag bytes are SHA-pinned and archive/OpenLDAP license inspected. Frozen Arch, Debian, Fedora 44, openSUSE and Ubuntu metadata was cross-checked; no recipe executed. All shipped mtest programs and installed API smoke are required. The full mtest sequence shares an explicitly initialized `testdb` environment, matching the prerequisite established by upstream's `test` target. A downstream portability patch keeps all transaction and cursor checks while removing their incidental dependency on LMDB's highly experimental fixed-address mapping mode, which is unsupported in the RVA23 QEMU environment. The file manifest includes the four `man1` pages present in the archive; this release does not ship a `man3` page.
