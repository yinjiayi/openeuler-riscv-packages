# lksctp-tools

This directory packages upstream `https://github.com/sctp/lksctp-tools` version `1.0.21` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The RPM file list keeps the generated inventory for installed payloads while
listing manual pages separately with compression-safe RPM path macros.
