# perl-text-csv-separator

This directory packages upstream `https://metacpan.org/dist/Text-CSV-Separator` version `0.20` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The fixed archive digest agrees with official MetaCPAN metadata and the
signature-verified PAUSE CHECKSUMS. The original README and module POD
record the same-Perl license grant. All original tests and fixtures are
preserved, and explicit BuildRequires cover the POD checks. The installed
smoke uses a fresh synthetic fixture to test delimiter detection with quoted
punctuation. No patch is needed.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
