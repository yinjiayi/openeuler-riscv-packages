# libconstant-defer-perl

This directory packages upstream `https://metacpan.org/dist/constant-defer` version `6` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The authorized official CPAN source SHA-256 is
`7b21263198ca22686efff3ae987a240be423dd2160afdeb29fe716d032986ffa`.
The publisher signed this SHA-256 in `CHECKSUMS` with its then-valid
historical key. The original author's embedded signature independently
binds all 47 non-signature files using the author's published historical
key; that legacy manifest does not replace the pinned archive SHA-256.
Debian stable 6-3 supplies naming lineage only.

The original full COPYING and Kevin Ryde's GPL-3.0-or-later notices are
retained. Neither bundled downstream recipes nor author tooling are run.
The original MakeMaker test suite is unmodified; the separate installed
smoke verifies that a deferred callback computes its result only once.
