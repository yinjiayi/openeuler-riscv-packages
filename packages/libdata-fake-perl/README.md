# perl-data-fake

This directory packages upstream `https://metacpan.org/dist/Data-Fake` version `0.006` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The fixed CPAN release is verified against MetaCPAN, signed PAUSE checksums, and Fedora 44 GA lineage. The original Apache license and exact generated MakeMaker, Test::ReportPrereqs, and embedded version::LAX notices are preserved from pinned donor archives. Donor code is not executed or installed.

The recipe runs all eight original default tests and explicitly packages the seven modules, Examples POD, and their eight manuals. The installed smoke exercises inclusive integer bounds, singleton selection, and a generated digit pattern.
