# caps-log

This directory packages upstream `https://github.com/NikolaDucak/caps-log` version `1.2.1` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

Packaging release 2 declares the Boost.ProgramOptions, OpenSSL, libgit2, and Git dependencies required by the upstream CMake project. It also records version `1.2.1` explicitly and enables the upstream test suite in the same out-of-source build directory used for compilation, installation, and CTest.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
