# libsodium

libsodium 1.0.22 for openEuler 24.03 LTS SP3 `riscv64`/RVA23. The
official release archive is SHA-256 pinned and inspected for safe archive
paths, links, and the ISC license. Frozen stable metadata cross-checks Arch
extra, AUR RPC, Debian stable, Fedora 44 GA, openSUSE Tumbleweed, and Ubuntu
GA. External recipes were neither read nor executed. The complete upstream
`make check` suite and an installed cryptographic API smoke test are required.
Apache-2.0 applies only to this repository's packaging material.
