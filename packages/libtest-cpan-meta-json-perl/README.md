# perl-test-cpan-meta-json

This directory packages upstream `https://metacpan.org/dist/Test-CPAN-Meta-JSON` version `0.16` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The archive SHA-256 is pinned from both MetaCPAN and the publisher's CHECKSUMS.
Upstream ships its Artistic-2.0 LICENSE. The original default MakeMaker test
suite is unmodified. Six author-only tests skip themselves by default.
The target smoke uses synthetic metadata and the installed validator API.
