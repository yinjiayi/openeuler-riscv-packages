# chibi-scheme

This directory packages upstream `https://github.com/ashinn/chibi-scheme` version `0.12.0` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

## Immutable source and licensing

Official stable tag `0.12` points to commit `08e23be118e7de8cf29d606bc4793371c0ace680`;
its `VERSION` is `0.12.0`. All 826 files of the SHA-256-pinned archive were checked
against that official commit's Git blobs. No upstream signature was advertised for
this tag/archive; a Git object match is not a cryptographic publisher signature.
The retained discovery snapshot is `discovery-20260808T165000Z-9a89920c269462cd`,
with AUR `chibi-scheme` 0.12.0-1 and Fedora 0.10.0-10.fc44 lineage; neither distro
recipe was executed or used as an authoritative license grant.

Root `COPYING` supplies the project's BSD-3-Clause grant. Complete `AUTHORS` and
all original per-file notices are retained in `%license original-notices`, copied
before generated files exist and made non-executable without changing their bytes.
The combined license expression also records the complete MIT notices in reference
SRFI implementations and explicit public-domain declarations (including Windows
lgamma and selected modules). `LicenseRef-chibi-scheme-public-domain` refers only
to those preserved explicit declarations, not to the archive as a whole.

`AUTHORS` attributes bundled benchmarks to the Racket Gabriel versions. In
particular `maze.sch`/`maze2.sch` retain their original third-party authorship;
their older/transformed contents are not claimed byte-identical to today's
Racket files. The official `racket-benchmarks` component's root license and
`info.rkt` permit MIT or Apache-2.0, with its named psyntax/pidigits exceptions
outside these fragments. This package selects MIT and pins the exact complete
official Racket MIT grant as auxiliary `Source1`. Source1 is license text only,
not additional program/test code or an artifact/provenance assertion. All
Source0 files, including benchmarks and their notices, remain untouched.

## Build, tests and installation

The recipe keeps upstream `all` and `install` without feature overrides: numeric
tower, Unicode, shared modules and Linux/POSIX module selection remain defaults.
Only standard `/usr` and `/usr/lib64` installation paths and distribution compiler
flags are supplied. Staged `DESTDIR` uses upstream's existing decision not to dump
runtime images; no image-related feature is disabled. No patch is applied.

`%check` runs the original default `make test` (`test-r7rs`) without test/group
filters. Since this original suite does not itself call `test-exit`, an additional
strict replay loads the same unmodified file and invokes its exported `test-exit`.
Chibi's `-l` resolves names by concatenating each module search directory, rather
than accepting a working-directory-relative or absolute path directly. The build
replay therefore explicitly prepends `tests` with `-I tests` and loads only the
basename `r7rs-tests.scm`. Installed replay similarly prepends the installed test
directory with `-I /usr/share/chibi-scheme-tests` before loading that basename.
Installed smoke verifies that file's exact source SHA-256, replays it through the
installed executable/modules, and checks bignum and Unicode output. It does not
recompile source or substitute a reduced test suite.

Declared build dependencies are bash, binutils, coreutils, diffutils, findutils,
gcc, glibc-devel, grep, make and sed. Runtime shell utilities are declared; ELF
library dependencies are generated by RPM. Full official base primary/filelists
were joined (18,503 packages, 2,207,942 paths) against a fresh matching repomd;
63-package closure with 32 version bounds resolved. No component name, source
alias, capability, upstream URL, owned path or private-prefix collision was found.
Two COPR signing-key filenames merely mentioning chibi-scheme provide no component
and intersect no planned path. This base-only audit is not a DNF solver run or
complete supplemental-generation namespace acceptance.

Local validation is limited to metadata, shell syntax, trusted tooling tests and
SHA-256 source-only verification. No upstream QA, RPM or QEMU build runs locally.
The package's all/install/default-test paths do not require downloads; the separate
Unicode-data regeneration targets are not prerequisites of those paths. Declaring
no upstream network requirement does not assert that hosted CI isolates networking:
the current shared workflow may still provide network-enabled build/install jobs.
RISC-V status remains `unknown` until exact-head hosted target build/default tests,
installation/smoke and physical RPM/SRPM acceptance; full actual supplemental
namespace, fresh protected checks and explicit squash remain separate merge gates.
