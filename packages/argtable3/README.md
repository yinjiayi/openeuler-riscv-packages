# argtable3

This directory packages upstream argtable3 3.3.1 for openEuler 24.03 LTS SP3
on `riscv64`/RVA23. CI downloads the official release asset over HTTPS and
verifies its pinned SHA-256 before building it.

External source licenses remain those of upstream. The repository license only
covers original packaging metadata, scripts, and documentation.
