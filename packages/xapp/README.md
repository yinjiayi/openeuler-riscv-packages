# xapp

This directory packages upstream `https://github.com/linuxmint/xapp` version `3.2.2` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

Release `2` declares the complete dependency closure required by the upstream
default Meson configuration: D-Bus, GLib/GIO, GTK 3, Cairo, X11, keyboard
layout support, StatusNotifier support, GObject introspection, Python overrides,
and Vala bindings. Exact-head run `33535083281` first exposed the missing
`dbus-1` interface; the remaining declarations follow the required dependencies
in the same verified upstream source tree rather than disabling features.

Release `3` uses the target Python site-architecture path to own the `XApp`
override bytecode generated by RPM post-processing. This keeps the complete
default feature set and the existing upstream test entry point unchanged.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
