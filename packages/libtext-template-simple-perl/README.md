# Text::Template::Simple

This directory packages upstream `https://metacpan.org/dist/Text-Template-Simple` version `0.91` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

The fixed CPAN archive agrees with the official MetaCPAN SHA-256 and the
publisher CHECKSUMS. The bundled LICENSE contains the author's original dual
Perl terms. Plain ExtUtils::MakeMaker needs no bundled loader include path.
The original default tests are retained, including the Devel::Size-dependent
assertions; the two author-only files and one release-only file retain their
upstream default skip behavior. The installed smoke exercises the module and
its `tts` renderer.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
