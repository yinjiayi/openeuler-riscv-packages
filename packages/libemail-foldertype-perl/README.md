# libemail-foldertype-perl

This directory packages upstream `https://metacpan.org/dist/Email-FolderType` version `0.814` for openEuler 24.03 LTS SP3 on `riscv64`/RVA23.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.

The official CPAN archive matches the signed PAUSE checksum and the identical
Debian stable original. The original full dual-license file and notices are
shipped unchanged.

The recipe preserves the upstream default tests and installs the module and
its four matcher plugins with their manual pages. The installed smoke checks
Maildir and Ezmlm directory markers, the documented MH path form, and the
default Mbox classification.
