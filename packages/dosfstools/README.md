# dosfstools

This directory packages upstream dosfstools 4.2 for openEuler 24.03 LTS SP3 on `riscv64`/RVA23. The network-enabled build enables compatibility links and keeps the complete FAT filesystem test suite.

External source and patch licenses remain those of their respective upstream projects. The repository license only covers original packaging metadata, scripts, and documentation.
