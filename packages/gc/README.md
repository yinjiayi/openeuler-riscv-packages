# gc

Boehm-Demers-Weiser conservative collector 8.2.12 for openEuler 24.03 LTS
SP3 `riscv64`/RVA23. The official release archive is SHA-256 pinned and
was inspected for path, link, and upstream HPND license safety. Frozen stable
lineage cross-checks Arch core, AUR RPC metadata, Debian stable, Fedora 44 GA,
and openSUSE Tumbleweed. No external recipe was read or executed. The full
upstream `make check` suite, including the C++ interface, and an installed
allocation smoke test are mandatory. Apache-2.0 covers packaging material only.
